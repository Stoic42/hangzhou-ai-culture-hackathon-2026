## 技术决策（已确认）

- **FastAPI + SQLite**（stdlib sqlite3），Python 3.12（`py -3.12`）；依赖：fastapi、uvicorn、python-multipart、jinja2（+ httpx 供测试）。
- **管理后台**：FastAPI 内置轻量后台（Jinja2 服务端渲染 + 少量原生 JS），与 API 同进程同端口，零 Node 工具链；受 `ADMIN_TOKEN` 保护（env 配置，表单/Header 携带），不进库。
- **stub 优先 + 可插拔 Provider**：`ASRProvider` / `GenerationProvider` 接口，默认确定性 stub，可注入 503/429/识别失败；remote.py 占位读 env。
- **一个 feature 单元**覆盖整个 server：`.codestable/features/2026-11-06-server-generation-library/`，`feat/server-generation-library` 分支/worktree，完成后回写 items.yaml。

## 关键实现点

1. **校验器复用与收紧**：import `shared/tools/validate_buddies.py` 的 `validate_manifest`，追加设备侧硬约束（≤16 节点、≤8 迁移/节点、≤6 动作/列表、≤4 变量/资源/标签/palette；条件 `right` 必须 int），保证过服务器校验即可真机运行；加与三只预设的一致性测试。
2. **content_hash**：sha256 于 content 四字段规范化 JSON（UTF-8、key 排序），定义写入 README 供设备侧对齐。
3. **隐私约束**：识别文本仅服务端私有、随候选 24h 过期删除；原始音频识别后即弃不落盘；候选与响应不含原话——后台候选页也只显示元数据（时间、状态、主题标签），**不显示识别文本**。
4. **异步生成幂等**：同一 candidate_id 重复 POST 返回同一任务；succeeded 时 buddy_id 已可从公共库读取（同事务发布）。
5. **稳定分页**：published_at + buddy_id 双降序，opaque cursor 绑定顺序；撤回保留记录返回 410。
6. **管理后台页面**：
   - 搭子库：列表（含 content_hash、package_size、published_at、状态）、详情、一键撤回（二次确认，仅内部）。
   - 生成任务：pending/succeeded/failed 列表、error_code、手动重试失败任务。
   - 候选：元数据列表与过期清理状态。
   - 概览：请求量、429/503 计数、限流阈值查看。
7. **限流**：仅候选与生成接口按 IP 429；公共库与后台不受限；阈值走 config。
8. **codestable 工件**：feature 目录含 design / checklist.yaml（含 dod 命令）/ review，全部中文。
