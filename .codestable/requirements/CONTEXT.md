# 《当代妖怪收容所》领域术语

本上下文界定当前作品的独立搭子、语音创建、公共搭子库与短时游戏边界。初期《拓》《蓝》《剪》术语随历史方案归档，不属于当前领域模型。

## Language

**搭子**:
以用户的坏习惯为性格与游戏规则来源，可在一台涂鸦T5-E1设备上独立运行的互动妖怪角色；不是聊天机器人或云端服务的显示界面。
_Avoid_: 语音助手、远程角色窗口

**预设搭子**:
已经保存在设备上，无需联网即可选择和完整游玩的搭子。
_Avoid_: 离线演示视频、固定台词角色

**自定义搭子**:
根据用户表达现场生成，并能保存为独立搭子的角色；创建时需要联网，已有自定义搭子的本地切换与游玩不属于创建。
_Avoid_: 每次开局重新生成、仅网站可见的角色

**搭子库**:
保存在服务器上的全局公共搭子集合；所有联网设备无需登录即可浏览、获取和切换其中的搭子，不需要设备间配对或分享码。
_Avoid_: 好友分享、设备互传、私人搭子库

**候选搭子**:
服务器根据用户语音提出的名称、性格与玩法简介，尚未生成具体逻辑，也未进入公共搭子库；只有用户确认后才成为可生成的搭子方案。
_Avoid_: 已发布搭子、预定搭子

**搭子内容**:
创作者确认前看到并确认的名称、性格与玩法简介，也是公共搭子库向其他设备展示的内容；不包含创造者原话，也不把具体执行逻辑作为公开介绍展开。
_Avoid_: 原始语音识别文本、规则源码、创造者录音

**本地搭子**:
设备上已经能够完整游玩的搭子，包括随设备预置的搭子和从公共搭子库下载后缓存的搭子；选择、切换与游玩本地搭子均不需要联网。
_Avoid_: 仅缓存介绍、离线试玩片段

**已发布搭子**:
已进入全局公共搭子库、身份与内容保持不变的搭子；修改已发布内容需要形成新的搭子，而不是覆盖原有搭子。
_Avoid_: 原位编辑、覆盖更新

**搭子游戏**:
由一只搭子的性格与行为规则构成的60—90秒完整体验，仅需标准涂鸦T5-E1设备即可运行，可重复游玩并包含有限阶段与分支，以“破解成功”或“被搭子带跑”收束，不依赖长期成长或连续关卡。
_Avoid_: 长期养成、跨天任务、无限聊天、必需外设
