# 压力值取代硬倒计时，并扩充输入动词与硬件KEY键

## Context

既有设计中每只搭子提供60—90秒游戏，倒计时归零无视规则直接判负（被搭子带跑）。联调试玩暴露两个体验问题：玩家不做任何操作干等一分多钟也会失败，过程枯燥；输入只有点击、滑动（无方向）、长按三种，且离线预设与服务器生成器实际只有“长按拒绝×3”一个玩法模板，重玩无差异。T5-E1板载的用户KEY键与QMI8658六轴IMU均未使用。

## Decision

1. **压力值取代硬倒计时**：压力随时间自动上涨（侵蚀式），正确操作大幅降压、错误操作小幅升压；压满判“被搭子带跑”，清空判“破解成功”。不操作约20—30秒即失败，单局时长由玩家行为决定而非固定计时器。
2. **输入动词扩充**：引擎在点击/长按/滑动之外新增方向滑动（左/右/上/下）、连点与节奏、摇一摇（SHAKE）三类事件；IMU只做摇一摇，不做翻转等更多姿态。语音识别仍不进游戏规则，维持“游戏不依赖语音”的原决策。
3. **服务器生成器模板库**：由单一“拒绝×3”模板扩充为4个经过验证的规则模板（拒绝×3、方向滑动对抗、连点节奏、摇晃甩掉），LLM生成时选择模板并填参数（速度/次数/文案），不做自由规则组合。
4. **重玩差异**：结局屏给出S/A/B/C评级（按剩余压力/用时/连击）与妖怪吐槽或夸奖文案；不做每局规则参数随机化。
5. **硬件KEY键**：单击为返回上一级，游戏中单击直接退出对局并按“被搭子带跑”记录（配吐槽文案）；按住为PTT语音输入（用于创建搭子流程），松开结束录音。PWR电源键保持系统用途，不复用。

## Consequences

正面影响：

- 消除“干等失败”的枯燥段，紧迫感由侵蚀机制持续提供，单局自然收敛在约20—60秒。
- 输入动词从3种无方向手势扩充到6种事件，自定义搭子玩法从1种模板变为4种，重玩有评级目标。
- KEY键复用单击/按住两语义，解决游戏中无法快速退出与语音创建需要按住说话两个痛点，不新增硬件。

代价与约束：

- 引擎需新增事件类型（方向滑动、连点计数、SHAKE）与压力值规则字段，规则包格式与校验白名单同步升级，既有预设与已下载搭子需兼容或重发。
- 服务器模板从1个增至4个，验证与仿真测试工作量相应增加。
- KEY键GPIO与QMI8658驱动接入需实机验证；评级数值与压力曲线需要调参。
