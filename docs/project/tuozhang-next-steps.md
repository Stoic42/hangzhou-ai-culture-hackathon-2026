# 《拓章》候选：审阅与下一步

2026-11-05傍晚。本轮审阅物品直接压印、AI纹样卡及StackChan交互的讨论版。未定题，未验证材料或机构；下文是建议，不能计为已完成功能。

## 先修正的假设

- **工艺**：给实物上墨后压纸属于直接压印；传统传拓通常先上纸、再在纸面上墨，见[中国非遗网](https://www.ihchina.cn/ky_zx_detail/21997.html)。机构及文化介绍应与实际流程一致。
- **图像关系**：AI线稿未变成实体印版，不能声称纸上的纹理由该线稿产生。平面手写稿也不能自动成为凸版。建议记录“原物→真实印样→纹样卡”。
- **彩墨屏**：一块借用屏作为展台展示卡；观众带走纸质印样，不能把设备当批量赠品。
- **机构**：舵机摇臂的圆弧不等于压头直线运动；5–8mm行程、所需压力及一次成印面积都未验证。先做导向/传动试验，再确定打印件。
- **StackChan**：点验上电与远程收图是两个验收。本地文件对固件状态有冲突，尚无传图接口及运行记录，HTTP传图列作待开发功能。
- **T5**：“核心板必定无音频、无额外底板即不能用”不能套用所有型号；官方[T5AI-Core套件](https://docs.tuyaopen.ai/zh/docs/hardware/tuya-t5/t5-ai-core/overview-t5-ai-core)与裸模组不同。是否使用按实物及适配工时决定。
- **展示事实**：纸张按实际使用记录，未收到的连史纸不能写成已完成材料；热敏打印机领到并出纸后才算备份。2寸屏3米可读、90秒全流程等均未验证。

## Pico 2 W缺线时怎样推进

用户确认板型为Pico 2 W，缺Micro-USB数据线，不是Pi Zero 2 W。官方[Pico文档](https://www.raspberrypi.com/documentation/microcontrollers/pico-series.html)说明其USB口兼具电源和数据；按住BOOTSEL插电脑后，Pico 2应枚举为`RP2350`存储盘。

| 顺序 | 建议操作 | 通过标准 |
|---|---|---|
| 1 | 借Micro-USB可传数据线，Pico先不接舵机，BOOTSEL插电脑 | 看到`RP2350`盘；未出现时换线或USB口复测 |
| 2 | 用已到手的纸墨及一个能平放的清晰纹理样品手工试印 | 相同组合连续3张可辨认，拍照记录；失败先调整材料和手法 |
| 3 | USB相机先接笔记本，固定光照和位置，拍原物与实际印样 | 两张清晰照片；不依赖Pi迁移或AI |
| 4 | 用实际印样做简单卡片，先在电脑显示 | 一幅图、一个名字、一个编号 |
| 5 | 分别验收Pico板载灯及StackChan一次远程改字/改图 | 每条链路有明确输入、设备结果；不一次集成全部外设 |

前4项可在约一小时内尝试，时长是目标。缺线时从材料与相机实验推进，不表示无线首次配置可免除。

## 之后再接舵机

Pico若需MicroPython，从[型号专用下载页](https://micropython.org/download/RPI_PICO2_W/)选择稳定UF2；先确认板上程序是否需要保留。PWM与总线舵机按实际型号分别处理：前者需正确PWM及匹配独立供电，后者需对应协议及匹配驱动。不能把总线舵机直接当PWM舵机。

若总线驱动板提供可用USB控制接口，可按其说明从电脑空载调试，未必需要Pico。型号/电压未确认前不提供通用接线和角度指令；空载通过后再验收导向、接触及有限行程。
