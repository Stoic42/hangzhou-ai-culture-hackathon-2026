# 讨论与状态记录

日期2026-11-05。本文件整理公开协作所需的结论，不收录聊天全文、私人档案或个人评价。

## 已明确的方向性要求

- 团队参加本场比赛，当前公开资料围绕硬件方向整理；具体赛道登记以组委会记录为准。
- 希望文化问题、AI作用与实体体验之间有清楚关系，不仅将文化内容放进聊天界面。
- 可用板子不必全部加入同一原型；micro:bit只有1块。
- 热敏纸不能替代真实剪纸用纸，打印幅宽也不能忽略。
- 已有工具可作为基础，不能因存在先例就否决整种题材，也不能忽略功能重合。
- 保留“AI生成效果图，再按工艺反推可制作方案”的路线，允许继续沿《蓝》探索。

## 尚未确定

- 最终选《拓》《蓝》还是《剪》。
- 《蓝》具体采用哪项工艺，做花版还是控染。
- 《剪》的实际输出方式与足够有用的实体反馈。
- 最终使用哪块板子、哪种执行器和哪些配件。
- 团队分工、设备领用及实际实验结果。

团队确认另有Raspberry Pi 5 16GB，并提出将拓印分成MVP与拔高版本。本轮仍是“如果选择拓印”的讨论，未确认最终定题。

新增[分阶段工程建议](../proposals/tuo-stages.md)：先验证材料流程，再分别完成小范围机械MVP、视觉反馈和自动定位补拓。验收标准是建议目标，尚无实机运行结果；全自动供纸、蘸墨和完整工艺不作为MVP承诺。

## 从早期计划中修正的表述

- “青取之於藍而青於藍”共九字，不能写成八字。
- 现场库存不等于本队物料，不能把40个舵机写成团队可领40个。
- HX711需实际称重传感器与合适采样/结构；不能仅凭模块名声称快速力度闭环。
- 摄像头拍摄或OCR不自动构成视觉反馈控制。
- 普通3D复制板不是文物原件，教学试样不自动证明文化抢救能力。
- 路演稿不采用未经发生证明的实地经历、机构对接或合作关系。
- 不从成员家乡推定方言能力；不采用未经核实的“方言染变”历史叙事。
- 不再使用“全部真染都需要跨周”“某题材必然撞题”的断言。
