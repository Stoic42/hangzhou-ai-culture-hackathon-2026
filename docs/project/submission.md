# 提交与路演材料

来源：[赛事指南](https://ai-gongfang.feishu.cn/wiki/XBWpwiOC0i9SXbk1QRbcNePenTg)，2026-11-05核对。提交时刻、表单与文件限制待现场确认。

## 硬件赛道材料

- [ ] 可运行、可现场演示的实体原型。
- [ ] PPT：文化问题、设计思路、技术链路、实际验证与下一步。
- [ ] 200字以内创意说明，可放入PPT。
- [ ] 作品名、团队成员与现场展示资料。
- [ ] 2分钟以内功能视频（指南列“如有可写入PPT”）。
- [ ] 既有成果与比赛期间有效增量说明。

软件方向还需要可在线访问、实际可操作的入口，可参考指南中的魔搭创空间部署建议。

## 创意说明草稿结构

```text
作品名称：待定
面向谁／什么文化场景：
希望解决的具体问题：
观众怎样参与并得到什么：
AI承担什么：
设备制作、操作或测量什么：
本次已完成的原型范围：
```

## 演示证据

优先展示一次实际输入、真实材料交互和结果。涉及缓存、回放、预生成或人工操作时清楚说明；不把目标能力、模型输出或机构计划写成已运行成果。

路演正文和详细表分别出现8分钟、7分钟两种时长，最终以组委会确认为准，见[赛程待确认项](../event/schedule.md)。
