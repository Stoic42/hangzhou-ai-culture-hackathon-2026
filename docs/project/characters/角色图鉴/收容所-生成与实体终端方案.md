# 当代妖怪收容所｜从一句坏习惯到一只住进实物的妖怪

本稿是当前黑客松的实施提案。现场按一块可复用圆屏、一台开发电脑和可用的 3D 打印机设计。已验证的是预设像素图的显示与触摸。生成服务、动态图包下载、传感器和语音台词均需实现和联调。

## 观众的一次体验

观众在电脑网页输入「我睡前总想再看一条猫视频」，网页生成一只新妖，例如「衔尾灯狸」。它有一对月牙耳，尾尖叼着另一轮小月亮，每想续看一条，月亮就又多一轮。观众看到自己的像素小像、名字、习性和它能住进的设备，点「收容到湖塔」。圆屏显示新妖。把自己的手机搁进塔前的湖面，妖怪收起月亮；很快拿走，它又露出一只眼。完整演示要让同一只新妖出现在网页、服务器图鉴和真机。

借《山海经》记录栖地、形貌、声音、习性的写法。地方景观和文物给形象提供依据，妖名及习性均标作当代原创。生成端保留一条设计解释，例如「眼里叠着月影，因为你说一条总会变出下一条」。

## 三种外壳，共用一块屏芯

| 栖所 | 现实动作和反馈 | 比赛取舍 |
|---|---|---|
| 湖塔「最后一条」 | 约定时刻到且托为空，语音轻催一次。放下手机并稳定一秒，月影收拢。五秒内取走再捞一轮，持续停放则睡去。如果到点时已放好，直接睡去。忽略提醒也会自行收场。 | 先打印并做真机端到端验收。十秒、五秒等均为演示参数。 |
| 玉琮桌座「现在做」 | 创建时给出第一步和 X 秒，例如「写一个标题，20 秒后提醒」。首个字上屏，玉兽先迈步、撤销提醒。到点还没写，就播放一次「我脚都抬酸了，借我一个字？」。纯圆屏模式允许预约和一次自报开工。 | 时间由本地计时器管理。电脑便笺确认实际输入，中文等选字提交。无需检测人的姿势。桌座先做插卡或简单方框。 |
| 桂囊挂件「快选吧」 | 人遇到两个都接受的选项才主动唤它，例如午饭吃面或饭。桂囊先随机抱一穗，用户按一次选择接受或改选，它把另一穗收好。两色实体短穗用于佩戴与指示，首版用屏上两侧选择。 | 用同一屏换外壳演示。只有电池、供电与固定方式验过，才展示真正脱线随身使用。 |

StackChan 的可选角色是守夜员。联动方式验证后，让它在归月时低头一次。所有端读同一份妖怪定义，各自根据实体能力选择玩法。

## 湖塔怎么做

前面是低矮的手机浅槽，后面是一座放大的石塔剪影，圆屏朝观众打开展示窗。用同一块底板的另两座小塔或浮雕交代“三潭”，手机放平不会遮屏。圆屏做成可从背面抽出的模组，给 USB、复位键、喇叭、穿线和托板维修留空间。先用纸板试手机厚度与受力，再量实际屏板及带壳手机，打印一圈试装件，最后打外壳。底盘支撑手机重量，托板限位保护开关，侧下方留出声孔。

**传感器选择。** 首选低触发力的带柄微动开关。浮动托板带动开关，松手回弹，固件对持续状态去抖，并分别发出放入、取走。借料时确认有裸开关或能辨清供电电平的模块，接线前按所用板原理图核对可用引脚。若买不到开关而现场有 HX711 **和**匹配的称重片，可改用承重托，空托去皮，用队员不同手机实测进入与退出阈值。若两种都缺，使用队伍记录中已借的 USB 摄像头，固定看托上的格标，判定遮住与露出。本次目标是判断专用槽是否持续占用；钥匙或其他压住托盘的物品也可能触发。验收至少覆盖不同带壳手机、轻碰、取回、开机时已经有手机四种场景。

**声音。** 先把「该还月了」「这一轮我替你收着」录成两个短音频，统一音量，提供静音。当前板型有扬声器接口，按实际扬声器规格接入；如果板端语音还没联通，电脑先播放，现场说明实际声音来源。试听时特意把手机放上，核对出声孔没有被盖住。

## 生成和同步

1. 创建页提交坏习惯、可选名字、所选栖所。生成端输出妖名、性格、原创由来、造型配方、短台词和已验证的事件规则。首版可用模型选轮廓、耳尾、纹样及配色，服务器将像素图层合成待机、提醒、安定三帧。输入不同坏习惯应能产生可见轮廓差别。若接整图生成，放到后台任务，并返回生成中、完成或失败。离线展台的规则合成应明确标为程序生成。
2. 预设和自建妖怪使用同一种发布记录。SQLite 存妖怪 ID、修订号、创建者、可见范围、栖所、能力需求、规则和素材清单；文件存源 PNG、设备绘图数据和可选音频。默认同步到用户配对的屏，明确发布的条目进入公共图鉴。原始坏习惯由创建者决定是否展示。
3. 局域网电脑运行服务。每块配对屏开机或定期拉取图鉴版本，下载有变动的条目，先收目录，选中时取素材。验证完整性后切换本地版本，失败时保留旧版，断网继续运行已缓存的妖怪。所有屏看到同一图鉴，各自显示所选妖怪，倒计时和正在播放的动作由本机管理。
4. 现有 27 帧编译在固件里，用现场生成的新妖需增加载入资源入口。第一版沿用真机通过的透明像素表示，服务器预转换为设备可用数据；每只新妖先做三帧，每帧 64 × 64 × 4 字节。另为新名字、台词处理汉字字形覆盖，可由服务器将展示字卡栅格化。收容到真机不能依赖每来一人重新烧程序。
5. 首轮只用一块真屏。先打通一个新妖经服务器到达真屏，再刷新网页并重启设备，核对同一 ID 和版本仍在。网页中的第二终端预览可演示独立选角和同步，标明是模拟端。若 T5 的 Wi-Fi 拉包尚未完成，用电脑通过 USB 下发同一服务的包并标注 USB 桥接。

## 现场优先级

- 机械同学用纸板搭托、找开关，测试十轮放下与拿走，再打印塔体。给模型留一个可更换传感器的小抽屉。
- 软件同学先发布一只刚生成的妖，验证网页与真屏的轮廓和配色对应，再接入托盘事件和声音；模型密钥只放服务器。
- 先验收湖塔一套。其后接同一服务的玉兽计时模式，再考虑桂囊外壳、StackChan 和多真屏互通。展台可并列空壳、单真屏与标明模拟的预览。
