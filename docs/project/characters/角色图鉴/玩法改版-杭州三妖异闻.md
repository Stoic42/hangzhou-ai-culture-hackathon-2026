# 当代妖怪收容所｜杭州三妖异闻 · 黑客松版

现场按一块已验证能显示三只妖怪的圆屏、一台开发电脑安排。三只轮流住在同一块屏上。队友用电脑切场，观众只接触手机、纸卡或自己的任务。这份是可搭建的方案，现有固件仍需增加接收演示事件的入口。

## 主节目：最后一条 · 借月还湖

桌上画一小潭水，中间放一张黑白格纸，圆屏立在纸旁。外接 USB 摄像头朝下，只框住格纸。若现场缺摄像头，用电脑内置摄像头，先确认拍得到桌面。开演前示范员在电脑设一个十秒后的「睡前时刻」。

到约定时间，捧月绒兽从屏边探头，爪子捧着三轮越来越挤的月影。观众把自己的手机搁在潭心，格纸被盖住一秒，三轮月影慢慢合为一轮。它松爪睡去。若归月过程中又拿起手机，格纸重新露出，它睁一只眼，悄悄又捞出一轮月亮。第二次搁下还能哄睡。睡稳后这一场结束，移走手机供下一人体验。忽略它，它只打一次哈欠。

三潭印月的一点灯光可以映出多轮月影，像「最后一条」后面永远还有一条。沿用 plead、beckon、success、timeout，用圆形和透明度画月影。程序只判定格纸稳定遮住或露出，先采一帧空桌作为参照，不给物体分类。停留的手也可能触发，要在现场灯光下实测。

## 共用圆屏的另外两出戏

- **现在做 · 第一笔。** 电脑打开一个本地便笺，观众正要做的事情就是给一张空白页起标题。旁边像良渚玉琮一样外方内圆的玉兽蹲着，一只脚抬在半空。便笺收到首段实际文字，就发送一次事件；中文输入法等选字上屏再算，空格和删除键都不算。玉兽迈出一步，「我先迈了，下面你写。」屏幕渐暗，光标还在原处，人可以接着写。只看这张便笺，不需要监测其他应用。这个场景只用电脑和圆屏，可以先用它打通端到端。
- **快选吧 · 留一穗。** 在摄像头画面内并排摆两张画着标记的纸卡，边上用紫线、桃线或直接涂色。把两件都能接受的小事各配一种颜色，例如面或饭。桂囊先随机抱一穗，观众把真正想选的卡抽走。该侧标记消失、手移开后，桂囊就抱住同侧的穗，把没选的那一枝收进肚子。「这一枝，我替你留到下回。」两卡一起被遮时等候。反选也有自己的表情。满觉陇的桂花和绣囊流苏落在动作里。与手机场共用同一镜头，只换纸面。
- **StackChan。** 可以扮演守夜的收容员。如果队里的现有控制方式已经能让它点头或低头，收到「归月完成」时让它跟绒兽一起低头；先单独试一次动作。现场主节目只依赖圆屏，机器人联动排在主节目验收之后。

## 最短施工顺序

1. 在圆屏固件增加一个 USB 串口自定义命令。先让电脑手工发送「归月」并连试三次，每次只换一次对应画面。板上原有 B 口可收发控制台，项目需要新写妖怪事件回调；更新像素图要交给 UI 线程。
2. 接电脑摄像头，固定角度，在电脑上显示两个字「露出／遮住」。依次测手机放下、短暂伸手、手机拿走。在展台照明下连续五轮通过再接圆屏。开关灯晃动也触发就重新标定或缩小取景区。
3. 电脑把每次稳定变化送一次，屏上完成「醒来 → 归月 → 睡去」及中途反悔。请第一次来的人，在无人指屏的情况下把手机放下，看故事能否自然结束。评委到场前若视觉仍不稳，就演可真实响应第一次输入的「现在做」；要演「归月」可由队友按键代触发，并说明是手动演示。
4. 有余力再接双卡与机器人。两个扩展分别验收，任何一个缺料都不影响已跑通的节目。
