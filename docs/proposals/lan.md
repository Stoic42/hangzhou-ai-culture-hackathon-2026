# 《蓝》：从想要的纹样，到真实布样

状态：候选方案，未选定具体工艺、材料或架构。用户明确愿意沿本方向继续探索；以下两条工程路线尚未选择。更新于2026-11-05。

## 文化与工艺边界

关注人怎样把表达意图转化为真实花布，以及图案与材料过程怎样相互约束。

蓝印花布的镂版刮浆防染，与温州蓝夹缬的成对雕花板夹布印染，是不同的制作流程。本轮不得把它们拼成一套不存在的工艺。夹缬流程可参阅[苍南地方工艺资料](https://cnzx.cncn.gov.cn/art/2023/7/25/art_1302240_58827700.html)，体验案例见[良渚博物院](https://www.lzmuseum.cn/LiangBoXinWen/2023644167648.html)。

不采用“方言被染程度”对应靛染的旧比喻；不推定团队成员会说某地方言。不预测别队撞题率，也不把“任何真染都来不及”当作事实。

## 路线A：效果图转镂空花版

AI生成蓝白目标图 → 转换成符合制作约束的纹样 → 输出留/去区域、连接桥与实际尺寸 → 从花版重新预览 → 制作花版并试样。

### 技术重点

- 对纹样的主体、留白和细节进行取舍，明确正负形约定。
- 按实际材料和幅面修补连接、加粗细部；连通不等于强度充分。
- 图纸预览必须反映调整后的花版，不能用最初AI图片充当可制作结果。
- 验证打印或手工制版方式，以及花版接触材料后的效果。

### 硬件关系

普通3D打印可参与制作花版，但此时核心成果仍主要是软件设计工具。只有明确设备改善了哪一步操作或测量，才能形成更充分的智能硬件方案。

## 路线B：蓝色小样控染台

选择少数可达目标色阶 → 夹持小布样 → 控制浸入、提起与等待 → 固定条件下观察显色 → 决定是否继续下一轮。

### 技术重点

- 控制板负责机构与时间，图像处理/AI后端可在电脑上。
- 先测试已准备染液与布样，再决定是否加入自动动作。
- 摄像头湿布读数不能直接当作最终干布颜色；照明、拍摄时刻与材料状态需可比较。
- 使用实测色阶，不承诺任意目标图片都能精确染成。

### 硬件关系

设备真实改变布料状态，观察结果影响下一次动作。所需夹持/升降、供电、液体环境和颜色观察都未验证；本仓库没有可运行控染代码。

## 两条路线的取舍

制版解决“在哪里留白”，控染解决“材料过程与颜色怎么控制”，不是同一件事。剩余时间内优先选一个小样问题，不将AI制图、自动制版、自动刮浆和完整染缸一起承诺。

首轮需要记录：选定的具体工艺、材料能否及时取得、一次小样时长、可复现结果、设备具体帮助哪一步。模拟染色或用普通颜料测试时需说明实验材料，不标为完成传统靛染。
