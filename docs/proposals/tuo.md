# 《拓》：教学试拓与辅助上墨

状态：候选方案。已有阳刻板生成代码；未在本仓库确认打印、手工试拓、机械上墨或端到端演示成功。更新于2026-11-05。

## 想完成的体验

观众选择一个字，在教学复制板上形成真实纸质试样，再观察图像、理解文字与工艺。阶段目标是把一张纸做成清晰、可带走的拓片体验样品。

本方案使用复制板，不接触文物原件；不以此声称已实现文物抢救、专业传拓或残字复原。

## 最小流程

1. 制作50×50 mm“青”字试板，检查切片与实际表面。
2. 用真实纸、墨和上墨工具手工验证，记录纸张、固定方式、湿度、墨量与结果。
3. 连续完成清晰样品后，再尝试机械辅助一个小区域的上墨。
4. 拍摄实际样品。若做OCR，应将它与已知模板识别区分，并展示低置信度或错误。
5. 比较结果，决定下一步调整；观众带走实物。

## 硬件与AI各做什么

| 部分 | 可承担的作用 | 尚需验证 |
|---|---|---|
| 阳刻板、固定框、扑子 | 提供真实材料交互 | 纸面成像是否符合预期、是否移位或蹭脏 |
| 舵机与机构 | 辅助定位或按压/扑墨 | 覆盖范围、补墨、行程、力和重复性 |
| 摄像头 | 读取样品与模板的差异 | 光照、分辨率、角度、墨色可见性 |
| AI及图像算法 | 解释文字，辅助发现未着墨/模糊区域 | 已知模板上的OCR不自动等于抢救价值 |
| 控制板 | 接收传感、控制动作与交互 | 不必同时用StackChan、Pico和T5 |
| 测力（可选） | 记录慢速按压过程 | HX711需实际传感器，不能默认适合快速冲击闭环 |

## 先验证的三个难题

- 单摇臂如何覆盖整个字面，而不只在同一处按三下？
- 上墨工具如何补墨与均墨，纸如何固定？
- 哪项可观察结果能实质改变下一次操作？

未解决以上问题前，不把“自动三遍上墨”“力度闭环”“视觉闭环”写成已完成能力。具体三遍压力、行程与工艺口诀也不作为未经来源验证的传统规范。

## 已有代码

见[拓板原型](../../prototypes/tuo/README.md)。代码将文字mask加粗、保留内孔、生成带底板的阳刻实体，并输出预览和STL。

默认整板文字采用“青取之於藍／而青於藍”，共**九字**；附加文案为自拟文本。模型预览不证明已打印，也不证明可稳定试拓。

## 范围与演示

优先做小板、手动换纸、人工上墨/机械辅助的单步实验。墨水屏、多板通信、集字活动、残字候选解释都不是第一阶段必需功能。

如果使用录制、缓存或预生成解释，应明确标注。演示时长先实测，不承诺60秒全自动流程。

## 继续或暂停的依据

若相同材料下手工连续做出的样品仍不清晰，先修工艺；若手工效果稳定而机构显著降低成功率，保留人工操作、重新确定设备帮助哪一步。
