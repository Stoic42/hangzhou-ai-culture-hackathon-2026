# 三方案比较与验证门槛

2026-11-05讨论版。以下是工程判断，不是比赛评分预测或最终定题。

| 维度 | 拓 | 蓝 | 剪 |
|---|---|---|---|
| 希望交付 | 清晰可带走的试拓样品 | 可制作花版或可比较的蓝色小布样 | 可实际制作的剪纸方案与成品 |
| 已有代码 | 阳刻板生成脚本 | 无本仓库实现 | 无本仓库实现 |
| 核心物理验证 | 纸、墨、固定、覆盖与上墨 | 明确工艺后验证制版或控染之一 | 图纸输出到真实纸面，制作结构是否成立 |
| AI候选作用 | 解释文字、辅助分析试样 | 纹样构思或结合实测结果规划 | 意图转图案，并在制作约束下调整 |
| 硬件作用 | 操作材料或读取试样反馈 | 控染较直接；花版设计本身偏软件 | 当前主要偏软件，需明确实纸反馈价值 |
| 主要风险 | 机械链路、墨量、覆盖、纸面成像 | 材料、工艺跨度、颜色测量 | 基础功能重合、任意折剪过度承诺、输出方式 |

## 选择依据

每个候选先回答四个问题：

1. 观众亲手完成、拿走或学会什么？
2. AI处理了哪个实际任务？
3. 设备具体制作、操作或测量了什么？
4. 哪个实验结果能证明比原流程有所改善？

## 继续投入前的小样门槛

- **拓**：用相同材料手工连续得到清晰样片，再判断机械应帮助哪一步。
- **蓝**：取得材料并确认具体流程，至少得到可比较的小样；花版与控染分别判断。
- **剪**：用真实纸照图完成样例；检查细节、断裂、难度与预览的对应关系。

已有工具可以复用；“有人做过”不自动淘汰题材，“加了板子”也不自动构成技术增量。最终依据实物验证与团队投入能力选择。
