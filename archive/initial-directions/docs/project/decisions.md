# 讨论与状态记录（初期方向档案）

日期2026-11-05。本文件保存《拓》《蓝》《剪》阶段的历史结论，不是当前作品的开发计划。

## 已明确的方向性要求

- 团队参加本场比赛，当时公开资料围绕硬件方向整理；具体赛道登记以组委会记录为准。
- 希望文化问题、AI作用与实体体验之间有清楚关系，不仅将文化内容放进聊天界面。
- 可用板子不必全部加入同一原型；micro:bit只有1块。
- 热敏纸不能替代真实剪纸用纸，打印幅宽也不能忽略。
- 已有工具可作为基础，不能因存在先例就否决整种题材，也不能忽略功能重合。
- 保留“AI生成效果图，再按工艺反推可制作方案”的路线，允许继续沿《蓝》探索。

## 当时尚未确定

- 《蓝》具体采用哪项工艺，做花版还是控染。
- 《剪》的实际输出方式与足够有用的实体反馈。
- 最终使用哪块板子、哪种执行器和哪些配件。
- 团队分工、设备领用及实际实验结果。

## 从早期计划中修正的表述

- “青取之於藍而青於藍”共九字，不能写成八字。
- 现场库存不等于本队物料，不能把40个舵机写成团队可领40个。
- HX711需实际称重传感器与合适采样/结构；不能仅凭模块名声称快速力度闭环。
- 摄像头拍摄或OCR不自动构成视觉反馈控制。
- 普通3D复制板不是文物原件，教学试样不自动证明文化抢救能力。
- 路演稿不采用未经发生证明的实地经历、机构对接或合作关系。
- 不从成员家乡推定方言能力；不采用未经核实的“方言染变”历史叙事。
- 不再使用“全部真染都需要跨周”“某题材必然撞题”的断言。
- 2026-11-05曾确定优先细化《拓》，以真实人工试拓和图像反馈为核心；该决定随后随方向调整归档。
- 当时的首要场景为文化空间公众体验：普通观众无需预备知识即可参与，并可带走个人试拓样品。
- 体验兼顾试拓成像原理与所选汉字释义；信息顺序为先提供操作反馈、再呈现汉字解释。
- 第一版采用3—4块经过字形、实物试拓与释义验证的精选字板，不承诺现场任意输入并即时制板。
- 精选字板的文化主线为“一字一愿”：观众以汉字承载具体祝愿，并完成可带走的个人试拓样品。
- 观众直接选择精选字板，不增加祝愿理解或语音对话步骤；智能化价值主要体现在真实试样反馈。
