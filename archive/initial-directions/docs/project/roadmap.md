# 初期方案开发与验证计划（档案）

2026-11-05讨论版，2026-11-05归档。该计划服务于《拓》《蓝》《剪》，当前无实施计划。

## 第一阶段：确定核心实物体验

- 从三个方案选择需要优先验证的小样。
- 核对实际领到的硬件、型号和配件。
- 记录观众输入、物理动作、可观察结果以及AI承担的任务。
- 先完成手工/静态小样，确定材料流程是否成立。

## 第二阶段：一个最小链路

- 仅接入必要的控制板、输入和执行/测量部件。
- 跑通一条端到端流程，保存实验条件与结果。
- 观察结果用于一次真实调整，明确人工与自动部分。
- 测量一次体验的真实时长与连续成功情况。

## 第三阶段：11月6日集中开发

- 根据小样结果决定最终范围。
- 完善交互、固定结构与材料周转。
- 准备网络不可用时可清楚说明的演示方式。
- 开始PPT与视频，只写实际完成和有依据的内容。

## 第四阶段：11月7日提交与巡展

- 确认提交表单与官方截止时刻。
- 提前留出功能冻结、排错、拍摄与打包时间。
- 核对原型、PPT、创意说明、成员信息与视频。
- 15:00—18:00巡展时保留可反复体验的核心流程。

## 第五阶段：11月8日演示

- 按现场确认的时长准备讲解和答辩。
- 检查供电、线缆、材料、固定与备份文件。
- 区分现场计算、预生成内容和视频回放。
- 保存观众反馈与实际效果，作为赛后迭代依据。
