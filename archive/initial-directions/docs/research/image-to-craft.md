# 从AI效果图到可制作方案

状态：旧方案共用研究路线，已随《拓》《蓝》《剪》归档，暂无实施计划。2026-11-05。

## 起点

先让AI生成希望得到的效果，再像图片转拼豆图纸一样，计算尺寸、可用材料和制作结构，得到可执行方案。

流程：**目标效果图 → 按工艺调整图案 → 生成图纸与步骤 → 从图纸重建预览 → 实际制作与比较。**

这是寻找能接近目标的方案，不是从一张图片唯一恢复原作者的材料和制作过程。

## 不同工艺需要的信息

| 工艺 | 需要计算或确认的信息 |
|---|---|
| 拼豆 | 网格、实际品牌色卡、数量、尺寸 |
| 单层剪纸 | 正负形、留/去区域、连接关系、最小细节 |
| 镂空花版 | 模板连通性、桥宽、开孔、材料厚度与接触方式 |
| 折剪 | 在限定对称与折法下的剪线、重叠与展开关系 |
| 多层模板 | 分色、分层、层序、定位与实际对齐 |

同一图像的可行输出取决于材料、尺寸和工具；视觉相似也不等于结构相同。连通性检查不能替代物理强度试验。

## 候选处理步骤

1. 约定背景、主体和正负形，约束生成图的颜色数、细节与构图。
2. 分割与简化，去掉无法在选定尺寸制作的小区域。
3. 提取轮廓，检查独立区域、过细连接和孔洞。
4. 修补/改形，向用户展示损失或改变了哪些视觉信息。
5. 输出带物理单位的制作数据，再根据该数据渲染预览。
6. 用实体试样比较，记录实际材料参数。

图像分割、形态学、连通区域、轮廓和向量几何可考虑OpenCV、scikit-image及Shapely。大模型用于意图、构思与解释，不替代确定性尺寸与连接检查。

## 已有基础与可借鉴内容

AI参考图转拼豆图纸、图像转多层模板、自动桥接，以及对称图案转折剪方案，都已有产品或研究。见[参考资料](references.md)。这些公开能力尚未在本仓库逐项实测。

目前值得验证的技术展示是：**同一张图，直接描边有什么制作问题，按约束修改后能否实际做出来？**

## 硬件边界

图纸转换本身是软件功能。若要发展为硬件作品，需要确定设备在真实材料的制作、操作或测量反馈中承担什么作用。普通显示、语音和打印输出可改善体验，但不能代替这项论证。
