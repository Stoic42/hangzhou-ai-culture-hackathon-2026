# 《剪》：AI效果图转可制作剪纸

状态：已归档，暂无实施计划。没有确定硬件方案，也没有确认图纸生成、任意图像折剪或真实续剪功能已实现。归档于2026-11-05。

## 当前希望解决的问题

AI可以生成漂亮图案，但图案未必能在选定尺寸、纸张和工具条件下剪出来。本方向探索如何调整图案、保留表达意图，交付实际可用的制作方案。

保留真实纸、剪刀、折叠与展开的体验。热敏纸不替代红纸，窄幅热敏打印不作为大幅作品的默认输出手段。

## 候选流程

1. 用户选择表达意图、尺寸、工具和制作难度范围。
2. AI生成适合该范围的参考图。
3. 图像算法识别正负形、连接区域和过细部位，调整为可制作近似。
4. 输出实际尺寸的剪线/留去区域；只有满足限定对称结构时，尝试折剪方案。
5. 根据调整后的图纸重新预览，让用户看到实际可达的变化。
6. 用真实纸制作，对照结果修订。

## AI与确定性计算

| 问题 | 候选方法 |
|---|---|
| 想表达什么、哪些纹样可供讨论 | AI结合有来源的文化资料提出构思 |
| 图像边界、主体与留白 | 分割、二值化、轮廓与向量化 |
| 哪些小块会掉落 | 连通性分析与连接桥设计 |
| 是否过细、能否按这个尺寸制作 | 宽度检查、形状简化与材料小样 |
| 怎样对折剪出 | 限定折法与对称结构下分析；不保证任意图像可折剪 |

## 已有先例

基础模拟、折叠预览、连接警告、意图转纹样和图像转镂空模板已有工具与论文，见[参考资料](../research/references.md)。因此“先看展开效果”和“AI图片转SVG”不单独作为本方案的创新主张。

此前讨论过《下一刀》实体预演台，但其核心功能重合度较高，当前不将它列为首选。“剪错后根据剩余纸面重新设计”更难，尚未确认可行性或独特性，不能作为必做功能。

## 尚未解决的硬件关系

图案与图纸转换主要是软件。摄像头读取实际纸面可以改善体验，但需要证明读取结果改变了制作建议；附加语音板或灯效本身不解决这一问题。

图纸如何交到真实纸面也未定：A4打印、投影或刻绘等需确认设备可用，不能从现场热敏打印机推定。若只能交付图纸，应如实按设计工具描述，不宣称已完成智能制作装置。

## 最小验证

先用一种尺寸、一种折法或平面刻剪方式，完成几张有代表性的图。逐项比较原效果图、调整后图纸和真实成品，记录改动原因；不能仅凭模型输出“可剪”二字就判定通过。
